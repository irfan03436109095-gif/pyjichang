Windows 更新用了多少流量？先看传递优化活动，再核对机场余量

纸壳子2026-11-16— 次阅读
选购与预算

小流量机场套餐的余量突然下降，恰好 Windows 在更新，不能直接把两者画等号。Windows 的“传递优化”用于 Windows 更新、Microsoft Store 应用和部分微软内容的下载，可能涉及微软服务器或其他电脑。它有自己的活动记录；机场后台记录的是服务方按其规则计算的套餐用量。两边统计范围、时间和代理路径可能不同。

先查 Windows 这本账

在 Windows 11 打开“设置 → Windows 更新 → 高级选项 → 传递优化 → 活动监视器”，查看本月下载来源和上传活动。记下观察时间、来源类别和大致增量，不把“本月累计”误认成某一分钟的消耗。微软说明活动监视器能显示下载来源、平均速度和上传统计。

示意图：传递优化的活动记录与机场套餐扣量属于两本不同的账。

再查套餐这本账

在机场账号后台记录相同时间前后的余量，确认套餐重置周期、上传是否计量、是否有倍率。然后查看客户端连接模式与更新任务实际是否经过代理。若更新绕过客户端，Windows 有下载量也未必计入机场套餐；若走代理，扣量也不必与文件大小精确相等。不要用一张截图推断服务方多扣流量。

控制后续预算

若你希望减少与其他互联网电脑的共享，可在传递优化设置中选“仅本地网络设备”或关闭“允许从其他设备下载”；关闭后更新仍可能直接从微软取得。使用按流量计费的网络时，微软说明它不会自动向互联网其他电脑收发传递优化的更新片段。需要限制带宽，可看传递优化的后台下载限制，但微软明确指出这些限制不适用于手动发起的更新下载。设置改变后，用下一个实际更新时段重新观察两本账。

机场推荐中的小套餐预算应预留系统更新空间；真正的验收是活动监视器、代理路径和套餐余量在同一时段有可比记录，而不是宣称某个开关能让所有更新“零耗流量”。

资料来源

Microsoft：Windows 传递优化与活动监视器；Microsoft：传递优化与按流量计费网络。核验日期：2026-11-16（北京时间）。
